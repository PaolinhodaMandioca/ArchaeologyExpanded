# ArchaeologyExpanded Mod

## Descrição
**ArchaeologyExpanded** é um mod para Minecraft que expande o sistema de arqueologia, adicionando novos blocos suspeitos e itens exclusivos para explorar. Mergulhe em escavações emocionantes e descubra artefatos raros.

## Funcionalidades Principais
- **Novos Blocos Suspeitos:** Adiciona 11 novos blocos suspeitos, espalhados por diferentes biomas e estruturas.
- **Itens de Arqueologia Exclusivos:** Encontre e colecione 1 novo iten arqueológico, com sua própria utilidade.
- **Novas Mecânicas:** Introdução de novas ferramentas e métodos para escavar e descobrir esses blocos suspeitos e itens.
